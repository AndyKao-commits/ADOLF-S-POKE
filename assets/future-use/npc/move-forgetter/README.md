# 遺忘爺爺素材

## 檔案

- `move-forgetter.png`：遊戲實際讀取的透明背景像素素材，96 × 104 px。
- `move-forgetter-source.png`：高解析透明原稿，供日後重製動畫或其他尺寸使用。

## 遊戲連結

`js/systems/move-forgetter.js` 會載入 `move-forgetter.png`，以腳底座標對齊地面並縮放成約 58 × 63 px 顯示。素材尚未載入或載入失敗時，會自動顯示程式繪製的暫代人物，互動功能不受影響。

若之後替換正式素材，維持相同檔名與透明背景即可，不需要修改遊戲邏輯。

## 設計特徵

- 禿頂、兩側白髮、白眉與白鬍子。
- 深藍及紫色長袍。
- 右手持木製手杖。
- 紫色記憶魔法點綴，呼應「遺忘技能」功能。
- 素材本身不包含地板、場景、文字或陰影。
