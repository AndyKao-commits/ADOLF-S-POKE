# 開唱（私人派對用）

給自己家聚會的 Web KTV：**平板投電視當播放器，手機點歌**。不是販售產品。

## 派對怎麼開（推薦：Windows 控制台）

電腦負責跑伺服器；**平板／手機不用裝 App，只開網頁。**

1. 電腦安裝 [Node.js LTS](https://nodejs.org/)
2. 雙擊專案裡的 **`啟動開唱.bat`**
3. 第一次按「第一次準備（install + build）」
4. 按「啟動派對」→ 複製平板網址
5. **平板**打橫開啟該網址／`player.html`，投到電視
6. **手機**掃畫面上的 QR 點歌
7. 結束時在控制台按「關閉派對」

詳見 [`launcher/README.md`](launcher/README.md)。

> 也可選用「加入開機啟動」：開機後只開控制台，要唱再按啟動。

## 指令列（進階／非 Windows）

```bash
npm install
npm run build
npm start
```

終端機會顯示區網網址，例如 `http://192.168.1.23:8787`。

- 播放器：`/player.html`（平板）
- 點歌：`/remote.html`（手機）

## 兩端分工

| 裝置 | 頁面 | 負責 |
|------|------|------|
| 平板（投電視） | `/player.html` | 播放、字幕、包廂 QR、人聲消除處理 |
| 手機 | `/remote.html` | 搜尋點歌、插播、歌單、輕量遙控 |

## 功能摘要

- 4 位包廂號 + QR，多人同時點歌
- YouTube 搜尋（免 API Key），可加伴奏／KTV／karaoke／左伴右唱
- 待播／插播／置頂／刪除／再唱
- 遙控：播放暫停、切歌、重唱、±10 秒、音量
- LRCLIB 同步歌詞 + 逐字／逐行 highlight
- 選用：人聲消除（KarOK 風格 Mid/Side；原聲 MV 較有感）

## 私人派對範圍（刻意不做）

- 會員／付費／推薦碼
- 麥克風混音、OBS、虛擬音效裝置
